# Fire It Up

The first pictures from Harry's guitar riff, before the sword fight and before What's a Harness. One Grok Imagine motion pass of that riff is the clip in this folder. A separate toe-dip drew a countdown in code over the same recording and did not call a paid API.

Play: [fire-it-up-grok.mp4](fire-it-up-grok.mp4)

## Stack

- The guitar riff Harry already had. It was not regenerated.
- Grok Imagine video, for this clip. The key is `XAI_API_KEY`.
- ffmpeg, to keep the riff as the soundtrack.
- The toe-dip, not in this file, was Python, Pillow, and numpy. No Suno, no Higgsfield.
